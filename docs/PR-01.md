# Fundação do frontend

O projeto ainda não possuía aplicação executável. Esta entrega estabelece a base React + TypeScript + Vite para as US-01 a US-06, com repositório próprio em `Front` e branch `feat/us-01-a-06-fundacao`.

## Entregas

- Página inicial com título acessível e organização documentada de páginas, componentes, serviços, modelos e mocks.
- Modelos provisórios de usuário, jogo, nota, review, comentário, favorito e notificação; exemplos válidos e inválidos verificados por testes de tipos.
- Leitura assíncrona mockada de jogos, consulta por ID, erro simulável, dados isolados e seleção central de adaptador substituível.
- Rotas de Home, jogo, review, perfil, login e cadastro, com páginas provisórias e tratamento de URL desconhecida.
- Button, TextField, GameCard, Avatar e estados de carregamento, erro e vazio; primeiro uso em uma prévia explícita na Home.

## Validação

`npm run check`: 46 testes aprovados em 7 arquivos, incluindo 3 testes de tipos; lint sem any, TypeScript estrito e build aprovados. `git diff --check` sem problemas.

Inclui regressão de navegação completa do cartão para a página e de acesso direto às rotas de jogos, reviews e perfis: IDs com `%2F` literal mantêm seu conteúdo, sem serem convertidos em barra pelo roteador.

Histórico contém commits RED antes das implementações e commits de conclusão por US. US-02 é uma refatoração protegida pelo teste existente, conforme sua exceção explícita. Comandos e resultados estão em `docs/TDD.md`.

## Limitações

Sem remoto configurado, esta descrição é preparação local: nenhuma PR foi publicada. Destino remoto e branch base serão necessários para publicação.

Páginas além da Home permanecem provisórias. A prévia usa um jogo fictício e texto local; não implementa catálogo, busca, autenticação, publicação de reviews ou persistência após recarregar. Nenhuma conexão direta com IGDB, banco ou backend.

Contratos e decisões de produto pendentes estão em `docs/CONTRACTS.md`. A configuração de hospedagem futura deve fornecer fallback para `index.html` nas rotas do BrowserRouter.

Revisão US-05: rota e link de notificações removidos conforme requisito atual. /notificacoes é tratado como URL inexistente. Sino e modal pertencem à US-28. Validação atual: 106 testes, lint, tipos e build aprovados.
